# 行情：腾讯报价 + 东财汇总，归日跟行情时间戳

# Status

accepted

# 2026-10-24 修订（v1.4.0）

接入币圈与四市场恐慌指数后，数据源分工与两条新规矩：

# Decision

行情模块（v1.3.0）只接免密钥公开接口，分工如下：

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 自选与指数报价 | 腾讯 `qt.gtimg.cn/q=` | A股/港股/美股一个接口，GBK 文本；指数也走它（v1.4.0 起） |
| 八大指数（回落） | 东财 `push2` `ulist.np` | 腾讯没给全时才用 |
| 行业板块涨/跌榜 | 东财 `push2` `clist` | `po=1` 涨、`po=0` 跌，只取前排 |
| 涨停 / 跌停家数 | 东财 `push2ex` `getTopicZTPool` / `getTopicDTPool` | ZTPool 必须带 `date` |

- **规范代码就是腾讯的代码**（`sh600519` / `sz000001` / `hk00700` / `usAAPL`），
  各数据源之间不做换算。用户输 `510300`、`00700`、`aapl` 由 `normalize_code` 归一。
- **归日取行情自带时间戳的日期，不是本地「今天」**。周末与节假日自然落到
  上一个交易日。不同市场的交易日不对齐，所以显示时逐标的取
  「实时价，没有就取本地最新快照」，不假设大家同一天收盘。
- 快照按 `(day, code)` 唯一，同一天重复刷新只更新不插行。
- 拿不到的数据显示「—」，不编。东财 `DTPool` 实测时好时坏，失败就返回 `None`。

# Why

金十数据要 token（502 放弃）；东财 `push2` 一个调用能拿全八条指数，
比逐市场问八个接口便宜。腾讯一个接口覆盖三个市场的自选报价，
且它的代码格式可以直接当我们的规范代码存，省掉一整层换算。

「归日跟行情时间戳」是因为各市场收盘时间不同：美股收盘时 A股的下一个
交易日已经开盘，用本地今天当归日会造出未来日期的行。而逐标的回落
（`live or latest_quote`）是因为不同市场的交易日本来就不对齐，
硬凑同一天要么丢数据要么编数据。

# 腾讯返回的坑（都踩过）

- 名称和现价的字段位在各市场一致（1 和 3），但**行情时间戳的位置不统一**：
  A股第 28 位、港股 29、美股 27 或 29。所以时间戳用格式匹配找
  （三种时间格式 + 后两位须为像样的小数），不能用固定下标。
- 东财 `ulist.np` 的 `f86` 不是时间戳（是价格），别拿它当归日。
- `getTopicZTPool` 不带 `date` 参数会返回 `rc:102`。

# Consequences

- 新增自选时，代码先过 `normalize_code`：认不出就报错，库里只存规范形式。
- 测试夹具按真实响应形态构造（三个市场的时间戳位置故意不同），
  一律打桩 `net._opener`，一条真请求都不发。
- 行情同步挂在启动后台线程里，和节假日/汇率同一个「失败即静默」的规矩（ADR 0007）。

| 币圈恐慌指数 | `api.alternative.me/fng` | 真指数，0-100，timestamp 是秒不是毫秒 |
| 美股恐慌指数 | Yahoo `^VIX`（v8 chart） | 真指数，按锚点反向映射成 0-100 温度 |

**温度口径**：币圈与美股取真指数；A股/港股没有免费的官方恐慌指数，
用涨跌停占比与指数涨跌推算，界面明确标注「估算」，不假装是官方数据。

## 「有时拿不到数据」的根因与修法

用户截图：板块榜时有时无。实测结论：

1. **东财 push2 校验 Referer**。不带 `Referer: https://quote.eastmoney.com/`
   一律返回空（curl 与 urllib 都一样，与 UA 无关）。net.py 因此加了
   `referer` 参数，东财调用全部带上。
2. **push2 还会间歇性直接掐断连接**（RemoteDisconnected），同一个请求
   五发里可能只成一发。net.py 默认重试两次、退避 0.5s/1s，只对连接层
   失败重试，正常拿到内容（哪怕是对方的错误 JSON）不重试。
3. **push2 在某些网络下会被整体掐断**（实测沙箱代理就这么把 push2 拦了，
   而 push2ex 一直通）。所以指数改成**腾讯主源**：腾讯和自选同一个接口、
   字段布局一样、还自带时间戳，指数和自选合并成一次请求；东财 ulist 只在
   腾讯没给全时补缺。实测腾讯八个指数全部拿得到，稳。
4. 涨跌停走 push2ex，不受 push2 抖动影响。

## 币圈的归日

币圈 7×24 交易，快照归日取 **UTC 日期**（Binance 蜡烛的 openTime）。
UTC 日期常比股票交易日新一天（周六就是这样），所以 `drop_rows_after`
的残留清理**默认排除币圈行**——那不是垃圾，是真实数据。
