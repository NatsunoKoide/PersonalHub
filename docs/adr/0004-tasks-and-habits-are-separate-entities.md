# 任务和习惯是两张表，分开统计

# Status

accepted

# Decision

「每天喝 2L 水」这类重复行为建模为习惯，按日期逐次打勾，并计算连续天数；一次性待办建模为任务。两者的完成率在年度总览里分开成两条，不合并。

# Why

如果每天自动生成一条任务，任务完成率会被没做完的重复项持续拉低，用户看到的「今年完成度」就不再反映真实执行力；而习惯需要的是连续天数和坚持率，是另一种统计口径。这是两个不同的问题，混在一张表里必然有一边算错。

# Considered Options

- **统一为任务 + 重复规则**：表更少，但统计口径打架，且每天自动生成的记录会撑大任务表。
- **统一为习惯 + 一次性开关**：同样表更少，但一次性待办的逾期顺延语义无处安放。

# Consequences

- 日历视图里任务和习惯的完成标记要分别画，否则用户分不清哪个是当天该做、哪个是当天要坚持。
- 习惯记录表会随天数线性增长，是库里行数最多的表之一，年度视图的查询要按范围取而不是全表扫描。
